# 3D Developer Portfolio

A cinematic and interactive developer portfolio built around a 3D laptop experience.

Instead of navigating a traditional portfolio, users scroll through an immersive journey where the camera approaches a 3D laptop, enters its screen, and transitions into the project showcase.

## ✦ Experience

```text
Landing Page
     ↓
3D Laptop
     ↓
Camera Zoom
     ↓
Screen Entry
     ↓
Projects
     ↓
Horizontal Project Showcase
